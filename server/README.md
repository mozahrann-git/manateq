# خط استقبال مناطق

الرسائل بتدخل من هنا. ده الجزء اللي **مش** على GitHub Pages — لازم يشتغل على سيرفر حقيقي عشان Meta تقدر توصله.

---

## أول حاجة النهاردة (من غير سيرفر ولا API)

متستناش حاجة. **كل يوم مش بتجمع فيه، تاريخ أسعار ضايع ومش هيتعوّض.**

1. هات شريحة جديدة — الرقم ده هيبقى رقم مناطق للأبد، فاختاره كويس
2. نزّل **WhatsApp Business** عليها (مش واتساب العادي)
3. ابدأ كلّم السيلز واطلب منهم يضيفوك
4. **سجّل رقم كل سيلز على الموبايل ده** — قائمة البث مبتوصلش للي مش حافظ رقمك
5. كل كام يوم: افتح المحادثة ← ⋮ ← تصدير المحادثة ← **بدون وسائط**

وبعدين ادخّل اللي اتجمع:

```bash
node server/import-export.js ~/exports/شادي.txt \
  --rep "+201004412287" --me "محمد زهران"
```

`--me` باسمك زي ما هو مكتوب في التصدير، عشان رسايلك انت متدخلش.
زوّد `--dry` لو عايز تشوف هيدخل إيه قبل ما يكتب حاجة.

بيشتغل مع تصدير الأيفون والأندرويد، وبالأرقام الهندية والعربية. والتصدير مرتين مبيكرّرش — نفس الرسالة بتتعرف وبتتسكّت عليها.

## الاستقبال الآلي (الـ API)

### ١. حاجات إنت لازم تعملها بنفسك

مش هقدر أعملها ليك — محتاجة حسابك وهويتك:

| الخطوة | المكان | ملاحظة |
|---|---|---|
| حساب Meta Business | business.facebook.com | بإسم الشركة |
| توثيق النشاط | نفس المكان | ممكن ياخد أيام — ابدأه بدري |
| تطبيق جديد نوع Business | developers.facebook.com | ضيف له WhatsApp |
| ربط رقم | جوه التطبيق | **رقم تاني غير رقم الـBusiness App** |

> **الرقم اللي على الـAPI مينفعش يتفتح في تطبيق واتساب العادي، ومبيدخلش جروبات.**
> عشان كده طلبك إنك تاخد رقم ثابت بدل جروب هو الوحيد اللي هيشتغل.
> يعني هيبقى معاك رقمين: واحد للـBusiness App (جروبات ومحادثات)، وواحد للـAPI.

### ٢. سيرفر

أي استضافة Node بتدّي دومين HTTPS. المطلوب: Node 18 أو أحدث، وقرص ثابت للمجلد `data/`.

```bash
git clone <المستودع> && cd manateq
export WA_VERIFY_TOKEN="كلمة-من-دماغك"      # هتكتبها في Meta برضه
export WA_APP_SECRET="App Secret من تطبيق Meta"
export MQ_ADMIN_TOKEN="$(openssl rand -hex 32)"
export MQ_DATA_DIR="/var/lib/manateq"       # لازم يبقى على قرص دائم
export MQ_ORIGIN="https://mozahrann-git.github.io"
node server/index.js
```

الخادم بيرفض يقوم من غير المتغيّرات دي — عشان ميقعدش مفتوح بالغلط.

### ٣. اربطه بـ Meta

في إعدادات WhatsApp جوه التطبيق → Configuration:

- **Callback URL**: `https://دومينك/webhook`
- **Verify token**: نفس `WA_VERIFY_TOKEN`
- اضغط Verify and Save — المفروض يعدّي على طول
- وبعدين **Subscribe** على حقل `messages`

ولو مش عايز تنشر لسه، جرّب محلي:

```bash
node server/index.js &
curl "http://localhost:8787/webhook?hub.mode=subscribe&hub.verify_token=كلمة-من-دماغك&hub.challenge=123"
# المفروض يرجّع: 123
```

## اللي بيحصل لما رسالة توصل

1. **التوقيع بيتفحص.** أي طلب من غير توقيع صح بيترفض ومبيوصلش للتخزين
2. **الخام بيتكتب الأول** في `data/raw/YYYY-MM-DD.jsonl` — حرف بحرف زي ما وصل
3. **القارئ بيشتغل** بنموذج المرسل نفسه
4. لو القارئ وقع، **الرسالة محفوظة برضه** وبتستنى بني آدم. مفيش رسالة بتضيع أبداً
5. Meta بتعيد الإرسال أحياناً — المكرر بيتعرف وبيتسكّت عليه

**القاعدة اللي بنمشي عليها:** الخام مقدّس. القراءة ممكن تتعدّل وتتعاد ألف مرة، والأصل مبيتلمسش.

## الواجهة

كلها محتاجة: `Authorization: Bearer $MQ_ADMIN_TOKEN`

| | |
|---|---|
| `GET /api/stats` | الأعداد |
| `GET /api/queue?status=pending&limit=50` | الطابور بنصوصه وقراءته |
| `GET /api/reps` | السيلز ونماذجهم |
| `POST /api/decide` | `{id, status, who}` — اعتماد أو رفض |
| `POST /api/rep` | `{phone, nm, dev, reg, projects}` — تعريف رقم مجهول |
| `POST /api/correct` | `{phone, id, field, line, value, who}` — تصحيح بيتعلّم |
| `POST /api/reread` | إعادة قراءة كل المستنّي بالنماذج الحالية |

`/health` مفتوح من غير توكن — للمراقبة.

## التصحيح اللي بيتعلّم

ده قلب النظام. لما تصحّح حقل غلط:

```bash
curl -X POST https://دومينك/api/correct \
  -H "Authorization: Bearer $MQ_ADMIN_TOKEN" \
  -H "content-type: application/json" \
  -d '{"phone":"201004412287","id":"M-5001","field":"price",
       "line":"سعر الوحده: 7,585,301 جنيه","value":7585301,"who":"محمد"}'
```

النظام بيطلّع القاعدة من السطر نفسه (الكلمة الدالة، الرقم الأول ولا الأخير، أقل قيمة) وبيحطها في نموذج **الشخص ده هو**. رسالته الجاية بتتقرا بيها على طول.

عشان كده بتقول للسيلز: «صحّحلي مرة، مش هسألك تاني».

## حاجة متعملهاش

في مكتبات بتربط واتساب العادي بالكود من غير API رسمي. **متقربش منها.** بتخالف شروط واتساب والرقم بيتقفل — ولو اتقفل بعد ما تكون جمّعت ٢٣ سيلز، هتخسرهم كلهم مرة واحدة.

## النسخ الاحتياطي

كل حاجة في `MQ_DATA_DIR`. انسخ المجلد وخلاص:

```bash
tar czf manateq-$(date +%F).tgz -C /var/lib manateq
```

`raw/` هو الأصل اللي مينفعش يضيع. `state.json` و`events/` ممكن يتبنوا من تاني منه.
