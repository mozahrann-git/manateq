# مناطق · استخبارات الاستثمار العقاري

منصة تحوّل رسائل جروبات المطوّرين على واتساب إلى بيانات استثمارية قابلة للمقارنة:
التكلفة الحقيقية للوحدة، مقارنة بمتوسط **الحي نفسه** مش متوسط المدينة، بحكم منشور ومصدر مؤرخ.

الموقع **ستاتيك بالكامل** — مفيش build ولا dependencies. ارفعه على GitHub واشتغل.

---

## التشغيل محلياً

```bash
# أي سيرفر ستاتيك يشتغل
python3 -m http.server 8080
# وبعدين افتح http://localhost:8080
```

فتح `index.html` مباشرة من الملفات بيشتغل كمان، بس السيرفر أفضل.

---

## الرفع على GitHub و التفعيل

```bash
cd manateq-site
git init
git add .
git commit -m "Manateq v1 — منصة استخبارات الاستثمار العقاري"
git branch -M main
git remote add origin https://github.com/<USERNAME>/<REPO>.git
git push -u origin main
```

بعدين في GitHub:

1. **Settings → Pages**
2. تحت **Source** اختار **GitHub Actions**
3. خلاص. كل `git push` على `main` بينشر لوحده.

اللينك بيطلع: `https://<USERNAME>.github.io/<REPO>/`

### دومين مخصص (manateq.com مثلاً)

1. اعمل ملف اسمه `CNAME` في جذر الريبو، جواه سطر واحد: `manateq.com`
2. عند مزوّد الدومين ضيف:
   - `A` → `185.199.108.153` و `185.199.109.153` و `185.199.110.153` و `185.199.111.153`
   - أو `CNAME` للـ`www` → `<USERNAME>.github.io`
3. **Settings → Pages → Custom domain** واكتب الدومين، وفعّل **Enforce HTTPS**

## تعديل البيانات

كل حاجة في `assets/js/data.js`:

| المتغيّر | فيه إيه |
|---|---|
| `CONFIG` | وديعة الصيانة، نسبة الإدارة والشواغر، سعر الشهادة والذهب، **قواعد الحكم** |
| `REGIONS` | المناطق الأربعة: متوسط المتر، الأحياء، العقود، السيولة |
| `LIQUIDITY` | متوسط أيام البيع لكل حي **وعدد العيّنات** |
| `GROWTH` | النمو السنوي المسجّل لكل حي |
| `DEVS` | المطوّرون وأدلتهم المؤرخة |
| `PROJECTS` | المشاريع: سجل الأسعار، خطط السداد، الرسالة الخام |
| `UNITS` | الوحدات |
| `POOL` | حوض طلبات العملاء |
| `EVENTS` | أحداث نبض السوق بثلاث صياغات (مستثمر/مشتري/بروكر) |

### إضافة وحدة جديدة

```js
{
  id: "MNQ-109", t: "شقة سوبر لوكس", r: "المقطم", d: "الهضبة الوسطى",
  src: "مالك مباشر", dev: "", proj: "",
  p: 2100000,        // السعر المعلن
  a: 120,            // المساحة
  rent: 14000,       // الإيجار الشهري · 0 لو تحت الإنشاء
  del: "فوري", k: "resale",
  maint: 0, club: 0, garage: 0,   // null = غير محددة من المطور
  locked: 0, lockWhy: "",
  docs: [["عقد مسجّل شهر عقاري", 1, "نسخة محفوظة"], ["معاينة ميدانية", 1, "1 Oct 2026"]]
}
```

> **`null` مش صفر.** `null` معناها «غير محددة من المطور» وبتظهر بالأصفر على الموقع.
> `0` معناها البند مش مطلوب أصلاً. الفرق ده هو اللي بيخلّي الموقع صادق.

## قواعد الحكم — منشورة

| الحكم | الشرط |
|---|---|
| **فرصة** | سعر المتر الحقيقي أقل من متوسط الحي بـ**5%+**، ومعاه استلام فوري أو خصم كاش 25%+ |
| **محايد** | قريب من متوسط الحي — سعر سوق عادل |
| **متضخّم** | أعلى من متوسط الحي بـ**8%+** من غير مبرر في الأوراق |
| **انتظر** | ورقة ناقصة أو إنجاز غير مرصود |

القواعد في `CONFIG.rules` وبتتغيّر من مكان واحد.

## المعادلات

```
التكلفة الحقيقية   = السعر المعلن + وديعة الصيانة + الجراج + اشتراك النادي
سعر المتر الحقيقي  = التكلفة الحقيقية ÷ المساحة
العائد الصافي      = (الإيجار × 12 × 0.9) ÷ التكلفة الحقيقية
مقابل الحي         = (المتر الحقيقي − متوسط الحي) ÷ متوسط الحي
أفق السيولة        = متوسط أيام البيع المسجّلة عند مناطق في نفس الحي
```

## الربط بقاعدة بيانات لاحقاً

`data.js` بيحط الداتا في `window.MQ_DATA`. عشان تربطها بـFirestore أو أي API،
بدّل الملف ده بالشكل ده والباقي مش هيتغيّر:

```js
fetch("/api/manateq-data.json")
  .then(function (r) { return r.json(); })
  .then(function (json) {
    window.MQ_DATA = json;
    // بعدين حمّل core.js وسكربت الصفحة
  });
```
